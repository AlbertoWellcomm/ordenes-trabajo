☁️ Conectar Nube Gratuita (Firebase)

Pasos sencillos para conectar 2 o 3 ordenadores gratis:
  1. Entra en console.firebase.google.com (gratis con tu cuenta de Google).
  2. Crea un proyecto (ej: Imprenta-Taller). En la sección Firestore Database, dale a crear base de datos en modo prueba o producción.
  3. En Configuración del Proyecto ⚙️ > Crear app Web </>, copia el objeto firebaseConfig.
  4. Pega el código aquí abajo y pulsa Guardar y Conectar. ¡Listo! Todo lo que guardes se sincronizará automáticamente en todos los ordenadores.
